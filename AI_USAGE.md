# AI Usage Log

This document tracks how AI (Claude, via Claude Code) was used while building the Currency
Exchange Tracker, from planning through implementation. It is updated in the same commits as
the code it describes, so entry order and commit history should line up.



## How entries are written

Every meaningful prompt gets an entry with:

- **Prompt** — what was actually asked (trimmed of restated context, kept verbatim otherwise)
- **Model returned** — a short summary of what came back (full diffs live in the commit, not here)
- **Decision** — Accepted / Edited / Rejected
- **Why** — the actual reasoning for that call
